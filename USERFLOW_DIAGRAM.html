Filtering & Blocking Pipeline

Platforms (4) → Format (video/short/article) → Language (12) → Followers (5 ranges) → Outlier (3×–50×) → Time (Week–All) → Sort (top/trending/recent/discussed) → Blocklist
  • Blocklist triggers: "Not in my language" → blockLanguage(), "Hide this creator" → blockCreator(), "Hide" → blockItem()
  • Reactive: dispatches tubeforge-blocklist-updated window event → useBlocklistSync bumps version → filter memos re-run
  • Persistence: localStorage tubeforge_blocklist
  • Component: FilterDropdown.tsx (320 lines, 18 props)

Generation (Shared)

callLLM — src/lib/generation/llm.ts

Single shared LLM wrapper used by all 5 generate routes. Each route passes its own CallLLMOptions (max_tokens, timeout, retries, empty fallback).
  • Env vars: KIMI_API_ENDPOINT, KIMI_MODEL, KIMI_API_KEY
  • Proxy routing: opt-in via KIMI_USE_PROXY=true
  • Exports parseJsonResponse<T>(content, fallback) — strips markdown fences, falls back to typed default
  • Schemas: src/lib/generation/schemas.ts — shared Zod schemas merged per-route
Phase 4 — Save to Board & Workspace Board

Save to Board Flow

From video/article card save button:
  1. Opens BoardPicker modal
  2. User picks a board (or default "My Ideas")
  3. handleSaveToBoard writes item to Firestore users/{uid}/boards/{boardId}/items
  4. Firestore unavailable → fails silently with toast
  5. Chat panel "Save all to board" uses localStorage directly (works regardless)
Hook

useBoardSave

Save-to-board picker state + handlers for the discover page.
Hook

useWorkspaceBoard (247 lines)

Active workspace + card CRUD for discover page workspace pane.

  • CRUD: loadWorkspaceCards, handleAddCard, handleDeleteCard, handleDuplicateCard, handleMoveToBoard, handleReferenceToBoard
  • Storage: Firestore (if signed in) + localStorage merge

  • Firestore paths: users/{uid}/boards/{boardId}
